# abhishekitconsults.github.io

ATS-friendly personal professional portfolio focused on:

- Microsoft Power Platform
- Microsoft Fabric
- Microsoft Azure
- Power BI / DAX / SQL
- Data Analytics
- Generative AI / LLM / RAG
- Python / APIs / Automation

## Before publishing

1. Replace `YOUR_EMAIL@example.com` in `index.html` with your actual email.
2. Replace `YOUR-LINKEDIN` with your LinkedIn username.
3. Add your actual resume as `resume.pdf` in the repository root.
4. Replace the project/experience placeholders with verified achievements, metrics and employers.

## GitHub Pages

Create the repository `abhishekitconsults.github.io`, upload these files to the root, then enable:
Settings → Pages → Deploy from branch → main → / (root).
