# abhishekitconsults.github.io

Website for Abhishek IT Consults.

## Publish on GitHub Pages

1. Create a GitHub repository named exactly `abhishekitconsults.github.io`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch → main → / (root)**.
5. The website will be published at:
   `https://abhishekitconsults.github.io/`

Before publishing, replace the placeholder contact email and any service text you want to customize.
